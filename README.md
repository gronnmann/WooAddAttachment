# WooAddAttachment
Simple plugin for adding attachments for 'Order Confirmed' emails from WooCommerce.

## Features
- Easily attach PDF documents to WooCommerce order confirmation emails
- Ideal for including terms and conditions, manuals, warranties, or return policies
- Works with the standard WooCommerce "Order Complete" emails
- Simple, user-friendly interface
- No coding knowledge required

## How to Use
1. Install and activate the plugin
2. Go to WooCommerce → Email Attachments in your WordPress admin
3. Click "Add Attachment" to select files from your media library
4. Save your changes
5. Done! These files will now be attached to all order confirmation emails
